How local summaries work

Local summaries use experimental LangMem + llama.cpp support. Native Codex compaction remains enabled; this does not replace or edit your conversation. Partial summaries are not ready for a handoff. Verify important details against original messages.

Start summary processes pending history in batches. Long tasks can take time. Cancel keeps completed batches; Start summary resumes them. New messages added during a job are included on the next run.

Summary size reduction describes local text only. It is not measured Codex usage or quota savings.
