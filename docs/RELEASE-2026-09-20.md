# Bundle controls, recovery, Serena and local summaries

Implemented with Ponytail's minimal-change approach and Wayfinder's domain/research workflow. The installed bundle remains the runtime; this repository contains its source and reproducible checks.

- Six independent switches cover RTK, local Headroom output, managed Headroom requests, Serena, LangMem summaries and llama.cpp.
- The existing tray service can recover a missing Headroom supervisor. Heartbeats, process identity, errors, and actual backend readiness are checked separately from the selected preference.
- RTK activity defaults to today's records, exposes recent/lifetime windows, and identifies outsized records. RTK is a command filter: ordinary shell commands do not automatically use it.
- Serena exposes four read-only navigation tools. Activation cannot expose editing tools, exact code is protected, and disabling blocks new calls in an already loaded bridge. Configured tools are not presented as proof that every Codex task loaded them.
- Local summaries require explicit task selection. LangMem runs with the existing local GGUF through llama.cpp, stores summaries separately, reports partial/stale coverage, supports cancellation, and unloads the model. No automatic inference, transcript replacement, or native compaction interception is introduced.
- Update and rollback controls now cover Headroom, RTK, Serena, LangMem and llama.cpp. Optional runtime candidates stay isolated until compatibility checks pass. llama.cpp candidates must also run the selected local model; model files are not upgraded automatically.

## Deployment and remaining limits

The changed installed files were backed up before replacement. Existing savings history, virtual environments, model files, managed routing, and unrelated Codex settings were preserved. Serena, local-summary tools and local model permission are enabled; no summary job starts until requested.

Restart Codex once to load the updated file tools and new MCP entries, then resume existing tasks. A full Windows reboot was not performed during this verification. Compression and generated summaries can omit useful information; exact retrieval remains available, and these checks do not establish unchanged quality for every future task. The displayed savings estimates are not measured weekly-quota or billing reductions.
