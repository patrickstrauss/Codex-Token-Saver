# Team first-run setup repair

Fresh installations now read RTK history from the same bundle directory used by the command launcher. An unused installation shows zero activity; corrupt or previously lost history still reports an error. Explicit dashboard environment overrides remain supported.

The installer writes verified local-tool and command-hook status receipts alongside Codex registration. These describe registration, not hook trust or proof that a task loaded the tools. Existing disabled choices, model, reasoning, authentication and routing are preserved. Receipt failures roll back registration without overwriting concurrent user changes.

Two launchers are included in the extracted deployment package and installed payload:

- **Repair-Team-Setup.cmd** repairs earlier team installations' RTK dashboard paths and integration receipts, retaining their source, runtimes, history and preferences. Restart the dashboard and reopen Codex afterward; review hook trust if requested.
- **Setup-Request-Compression.cmd** downloads the verified public compression model and validates the installed runtime, original-content retrieval and an isolated backend. It prepares a paused managed connection. Enable request compression explicitly in the dashboard after successful setup, then restart Codex once. Setup itself never changes the Codex route.

Validation covers fresh/empty/stale/corrupt RTK history, transactional registration and repair, disabled settings, concurrent writes, setup rollback and worker cleanup. The Windows packaging workflow additionally installs into a temporary directory and verifies real RTK initialization, dashboard defaults, artifact-based repair, repeated installation and synthetic Codex settings preservation. An isolated real backend probe verifies exact retrieval and source-bound readiness without a paid model request.

See [team installation and repair](TEAM-INSTALL.md) for steps and limitations. Native Codex compaction remains enabled. Reported reductions are estimates, not measured account-quota savings.
