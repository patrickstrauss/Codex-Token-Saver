# Local search candidates for Codex Token Saver

Research checked 2026-09-14. No installation, model download, indexing or configuration changes were performed. GitHub documentation and source were read directly over HTTPS because the web search tool failed to decode its responses. Cached primary documents are in `docs/research-cache/`.

## Recommendation

1. **Pilot grepai for code search.** Its native Windows executable, Windows CI, semantic search and call/reference tracing make it the strongest Windows-confidence choice. Use local Ollama embeddings and the default local file store. Expose its stdio MCP tools to Codex and request compact results. This is an integration proposal, not a verified Codex Desktop deployment.
2. **Consider QMD only for a sizeable Markdown/document collection.** It covers a different need from code search. Start with its lexical search and add semantic/reranking models only if retrieval quality warrants the extra resources. Windows needs a smoke test before inclusion.

CocoIndex Code is a credible **alternative to grepai**, particularly when explicit Codex documentation and automatically refreshed search are priorities. Do not install both code indexers by default: they would maintain overlapping indexes and embeddings.

All three select relevant content before it reaches the model, complementing RTK output filtering and Headroom request compression. They do not transparently intercept every file read: Codex must use their tools, and exact file reads remain necessary for edits. There is no measured savings percentage for this laptop yet.

## Verified comparison

| Project | Local operation and integration | Windows and resource evidence | Limitations |
|---|---|---|---|
| **grepai — MIT** | Local Ollama embedding provider, file-based GOB store, watcher for incremental indexing, stdio `grepai mcp-serve`. Tools include semantic search and call/property reference tracing; compact output is available. | Official PowerShell installer, native Windows code and Windows CI/builds. Default Ollama `nomic-embed-text` model layer is approximately **274 MB on disk**; this is not a RAM measurement. | Requires an embedding service and a running watcher for freshness. OpenAI, remote embedding endpoints and remote storage are optional; local privacy depends on selecting local settings. Explicit Codex-specific setup was not present in the MCP page inspected, so Codex compatibility is inferred from standard stdio MCP. |
| **CocoIndex Code — Apache-2.0** | AST-based semantic search, incremental indexing and `ccc mcp`; its README explicitly documents `codex mcp add cocoindex-code -- ccc mcp`. MCP searches refresh the index by default. The `full` install selects local SentenceTransformers embeddings; the slim install needs a cloud provider. | Python >=3.11. Published CocoIndex 1.0.23 dependencies include Windows x64 wheels; cocoindex-code 0.2.41 has a universal Python wheel. This supports a plausible native Windows installation, not proof of end-to-end operation. README estimates roughly **1 GB of Torch/transformers dependencies**. Default model is Snowflake Arctic Embed XS, about **22.6M parameters**. | Disable default anonymous usage telemetry using `COCOINDEX_DISABLE_USAGE_TRACKING=1` for an offline-oriented bundle. The project says telemetry excludes code, paths, queries/results and embeddings. Its advertised 70% token reduction is a project claim, not a measured guarantee here. |
| **QMD — MIT application** | Local BM25, vector search and LLM reranking for documents. SQLite index, explicit collection/update/embed steps; stdio or loopback HTTP MCP. Initial model downloads use remote hosts; inference is local afterward. | Node >=22 or Bun. Current package declares a Windows x64 SQLite vector dependency and README documents Windows CUDA behavior. CI currently covers Linux/macOS, not Windows. Three default models total about **2 GB of downloads**: ~300 MB embedding, ~640 MB reranking and ~1.1 GB expansion. CPU operation is supported; RAM/VRAM is additional. | Best suited to Markdown/notes/docs, not a replacement for code-aware navigation. Windows CUDA parallelism defaults to one because of a documented crash issue. The default EmbeddingGemma model has separate Gemma terms; the application's MIT license does not cover model weights. |

Local configurations do not incur embedding API charges. They still consume storage, CPU/RAM, electricity and indexing time. None of the inspected projects supplies a reproducible RAM bound or a token-saving result directly applicable to this laptop. Benchmark a representative task for relevant hits, missed symbols, stale-index behavior, exact-read count, latency, process memory and actual Codex usage before claiming a gain.
